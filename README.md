# Clothes E-commerce

For selling clothes e-commerce platform 


## Tech Stack

- Frontend: REACT, TYPESCRIPT, TAILWIND, PLAYWRIGHT

- Backend: NODE JS, EXPRESS JS, REST API, Jest + Supertest

- Database: POSTGRESQL

- Tools: Cursor, Docker, AUTHENTICATION (JWT)


### Main Features

- Auth (register, login)
- List produk
- Detail produk
- Cart
- Simple Checkout (without payment)
